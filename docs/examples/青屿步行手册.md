# 青屿步行手册

周末沿着河岸走一圈，从石桥出发，经过旧车站，在橘园补给。全程约 6 公里，预留两小时。

> [!tip] 出发前
> 石桥东口有饮水点。雨后改走堤顶步道，台阶湿滑。

## 路线一览

| 路段 | 距离 | 适合停留 |
| --- | ---: | --- |
| 石桥 → 旧车站 | 1.8 km | 河岸观景台 |
| 旧车站 → 橘园 | 2.4 km | 白色站房 |
| 橘园 → 石桥 | 1.8 km | 林间长椅 |
